# Lista de Materiales - Comedero Inteligente para gatos
Proyecto del curso EL-1200 Introducción a la Electrónica.

## Componentes que se utilizaron
| Cantidad | Componente | Función |
|---|---|---|
| 1 | ESP32 | Controla el funcionamiento del comedero. |
| 1 | Sensor PIR | Detecta movimiento cerca del comedero. |
| 1 | Servomotor | Abre y cierra la compuerta del alimento. |
| 1 | LED rojo | Indica cuando se está dispensando alimento. |
| 1 | Resistencia de 220 Ω | Limita la corriente que pasa por el LED. |
| Varios | Cables de conexión | Conectan los componentes electrónicos. |

## Software utilizado
- Wokwi para realizar la simulación del circuito.
- Biblioteca ESP32Servo para controlar el servomotor.
